# Security Policy

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Report it
privately through this repository's **Security** tab by selecting
**Report a vulnerability** to create a private GitHub Security Advisory.

Include the affected version or commit, reproduction steps, impact, and any
suggested mitigation. Maintainers will acknowledge the report and coordinate
validation and disclosure through the advisory.

This starter does not publish a fixed support or response-time commitment.
